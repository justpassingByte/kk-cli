# AgentKit CLI

`ak` installs, updates, migrates, diagnoses, and safely removes AgentKit kits.

## Install

```bash
npm install --global @bestagentkits/ak@beta
```

Node.js 22.14+ or Node.js 24+ is required.

## V1 commands

```text
ak login
ak logout
ak init
ak kit init
ak update
ak migrate
ak uninstall
ak doctor
```

The public beta prioritizes smooth authentication and recoverable kit lifecycle
operations on macOS, Windows, and Linux.
